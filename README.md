## 💡 О проекте

Шаблон веб-приложения для быстрой разработки. Фронтенд на React интегрирован с бэкендом на FastAPI, что обеспечивает удобную разработку, строгую типизацию и быструю сборку.

---

## 🛠 Technology Stack and Features

### Backend
* ⚡ **FastAPI** для быстрого и асинхронного Python бэкенд API.
* 🧰 **SQLModel** для взаимодействия с базой данных через ORM.
* 🔍 **Pydantic** для валидации данных и управления конфигурациями.
* 💾 **PostgreSQL** в качестве базы данных.
* 🔒 Безопасное хэширование паролей.
* 🔑 **JWT (JSON Web Token)** аутентификация.
* 📫 Восстановление пароля по электронной почте.
* ✅ Тестирование с помощью **Pytest**.

### Frontend & UI
* 🚀 **React** для пользовательского интерфейса.
* 💃 Стек: TypeScript, хуки, Vite.
* 🎨 **Tailwind CSS** и **shadcn/ui** для компонентов интерфейса.
* 🦇 Поддержка темной темы (Dark Mode).

### Infrastructure
* 🐋 **Docker Compose** для локального запуска сервисов.
